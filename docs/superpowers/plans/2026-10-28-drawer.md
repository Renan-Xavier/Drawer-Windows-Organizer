# Drawer (Desktop Icon Organizer) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the **Drawer** Windows desktop icon organizer with Discord-inspired blue geometric rounded drawers, directional sliding + smooth fade animations, auto-adjusting rectangular dimensions based on icon count, hover (1.25s persistence) & click-to-pin interactions, Windows icon scale sync, drag-and-drop, and a Windows NSIS `.exe` installer.

**Architecture:** An Electron desktop overlay application split into a pure, unit-tested core (`src/core/geometry.js` and `src/core/store.js`), an Electron Main process (`src/main/main.js`, `src/main/preload.js`, `src/main/icon-generator.js`) handling native Windows icons, Registry scale detection, file vaulting, and click-through window management, and a hardware-accelerated HTML5/CSS3 Renderer (`src/renderer/`).

**Tech Stack:** Node.js 24, Electron, `node:test`, CSS3 GPU Transitions, `electron-builder` (NSIS installer for Windows).

**Spec:** `docs/superpowers/specs/2026-10-28-drawer-design.md`

## Global Constraints

- App name: `Drawer`.
- Visual style: Blue rounded-square drawer (`#2563EB` / `#1E3A8A` palette), explicitly avoiding Windows Explorer yellow.
- Geometric expansion: Expanded drawer remains a rounded rectangle/square (`border-radius: 16px`) connected to the drawer, sizing tightly to `N` icons (`0->1x1`, `1->1x1`, `2->2x1`, `3->3x1`, `4->4x1`, `5+->4xceil(N/4)` horizontal or transposed when vertical).
- Animation: Smooth movement and opacity fade (`260ms cubic-bezier(0.22, 1, 0.36, 1)`).
- Hover behavior: Opens on mouse enter; remains open for `1250ms` (between 1.0s and 1.5s) after mouse leaves before closing.
- Click behavior: First click pins the drawer permanently open; clicking again unpins and closes it.
- Windows Icon Scales: Supports `small` (32px icons / 48px drawer), `medium` (48px icons / 64px drawer), and `large` (64px icons / 88px drawer), synced with Windows Registry `IconSize` or user selection.
- Packaging: Windows `.exe` installer built via `electron-builder` (NSIS).

## Review Focus

- Rapid mouse re-entry during the `1250ms` hover-leave countdown must cancel the close timer and keep the drawer open without flickering.
- Clicking a drawer that was already opened by hover must transition it directly to `pinned` (open) rather than closing it on the first click.
- Dragging a drawer near the right or bottom screen edge must recompute opening direction (`left` or `down`) and clamp coordinates so the drawer never renders off-screen.
- Deleting a drawer or removing an icon that was moved into the Vault must restore the file to the user's Desktop without data loss.
- Empty or whitespace-only drawer names must fall back to a default name (`"Nova Gaveta"`) rather than rendering an invisible label.
