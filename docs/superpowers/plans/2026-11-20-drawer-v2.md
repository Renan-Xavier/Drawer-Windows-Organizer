# Drawer 2.0 (Pods Nativos & Bordas Magnéticas) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Substituir a antiga sobreposição Electron em tela cheia por uma aplicação 100% Nativa Windows (C# / WPF DirectX + Win32 Shell COM) baseada em Pods Nativos Independentes com Encaixe Magnético nas Bordas, Menu de Botão Direito Real do Windows (`IContextMenu`), Execução Fiel de Atalhos (`.lnk`/`.url`/`.exe`), Catálogo Rápido de Apps e Inicialização Real no Registro do Windows.

**Architecture:** Cada gaveta é renderizada como uma micro-janela WPF nativa independente (`DrawerPodWindow`, `WindowStyle.None`, `AllowsTransparency = true`, `WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE`) ocupando apenas sua própria área geométrica (zero janela de tela cheia, zero barra superior, zero loop de hit-test em Node.js). O motor `Win32ShellService` integra diretamente com as interfaces COM da Shell do Windows (`IContextMenu3`, `IShellLinkW`, `IShellItemImageFactory`, `ShellExecuteExW`) e com o Registro (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).

**Tech Stack:** C# (.NET Framework 4.8 `csc.exe`, WPF `PresentationFramework` / `PresentationCore` / `WindowsBase`, WinForms `NotifyIcon`, Win32 Shell COM `shell32.dll` / `user32.dll`), Node.js (`node:test`) para suíte de testes automatizados e pipeline de build/empacotamento.

**Spec:** `docs/superpowers/specs/2026-11-20-drawer-v2-design.md`

## Global Constraints

- Plataforma alvo: Windows 10 / Windows 11 x64 usando o compilador nativo `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`.
- Compatibilidade total de dados com `%APPDATA%\Drawer\drawers-state.json` e `%APPDATA%\Drawer\vault\<drawerId>\`.
- Zero sobreposição em tela cheia: cada gaveta deve ser uma janela nativa independente (`WindowStyle.None`, sem barra de título).
- Seletor de arquivos e Drag & Drop nunca devem desreferenciar `.lnk` destrutivamente (`DereferenceLinks = false`), preservando argumentos e diretório de trabalho.
- Limiar de encaixe magnético de borda: `SNAP_THRESHOLD_PX = 18` para as bordas `left`, `right` e `top`.
- Tempo de recolhimento por hover: `1250ms`; transição de abertura/fechamento: `260ms`.

## Review Focus

- Atalhos `.lnk` que dependem de argumentos e `WorkingDirectory` (ex.: `Update.exe --processStart Discord.exe`) movidos para o Vault precisam continuar abrindo com seus argumentos e pasta de trabalho originais.
- Atalhos `.url` (ex.: jogos da Steam `steam://rungameid/...`) devem abrir via protocolo na Shell do Windows sem erro de caminho inexistente.
- Arrastar uma gaveta para perto das bordas esquerda, direita ou superior (`<= 18px`) deve encaixá-la magneticamente (`dockedEdge: 'left' | 'right' | 'top'`) e forçar a direção de abertura para dentro da tela (`right`, `left` ou `down`).
- Ativar/desativar "Inicializar com o Windows" deve gravar e remover de verdade o valor `"Drawer"` em `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
- O Catálogo Rápido deve listar `.lnk` e `.url` reais da Área de Trabalho e do Menu Iniciar sem duplicatas e ignorar desinstaladores (`uninstall` / `desinstalar`).

### Task 4: Janelas de Pods Nativos WPF, Catálogo Rápido e Orquestrador (`src/native/DrawerPodWindow.cs`, `src/native/AppCatalogWindow.cs`, `src/native/DrawerApp.cs`)

**Interfaces:**
- Consumes: `DrawerStateStore`, `Win32ShellService`, `MagneticDockCalculator`, `GridGeometryCalculator`
- Produces:
  - `DrawerPodWindow`:
    - Micro-janela WPF transparente sem bordas (`WindowStyle.None`, `AllowsTransparency = true`, `ShowInTaskbar = false`) que renderiza o Pod estilo Discord (prévia `2×2`, badge de Pin/Borda, rótulo editável e painel geométrico expansível com animação suave `260ms` e timer de hover de `1250ms`).
    - Quando `dockedEdge != "none"` e fechada, recolhe-se na borda do monitor como uma **Aba Magnética Retrátil estilo Discord** com `Topmost = true`, deslizando para dentro da tela ao encostar o mouse.
    - Suporte a Drag & Drop nativo OLE (`AllowDrop = true`, `DataFormats.FileDrop` e arraste de itens entre gavetas ou de volta para a Área de Trabalho).
    - Clique simples nos ícones abre o programa via `Win32ShellService.OpenItemFaithfully`; clique com o botão direito abre o **Menu de Contexto Real do Windows (`IContextMenu`)** via `Win32ShellService.ShowNativeShellContextMenu`.
  - `AppCatalogWindow`:
    - Janela WPF moderna com abas/seções para **Catálogo Rápido de Aplicativos** (busca instantânea em todos os atalhos da Área de Trabalho e do Menu Iniciar para adicionar com 1 clique, além de botão `"Procurar Arquivo/Atalho..."` com `DereferenceLinks = false`) e **Configurações Gerais** (Escala sincronizada com Windows, Tema Azul Discord / Transparente, Inicializar com o Windows, Guardar arquivos do Desktop no Vault, gerenciar/criar gavetas).
  - `DrawerApp`:
    - Single-instance mutex, ícone na Bandeja do Sistema (*System Tray*) com menu completo, atalho global `Ctrl + Shift + D` (*Peek Mode* para trazer os Pods por cima de qualquer janela aberta), e modos CLI `--self-test` e `--smoke-test`.
